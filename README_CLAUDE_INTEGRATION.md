## Step-by-Step Setup

### Step 1: Get Your API Key (2 minutes)

**Go to:** https://console.anthropic.com/account/keys

1. Sign in (or create free account)
2. Click **"Create Key"**
3. Copy the key (starts with `sk-ant-`)
4. Keep it safe

**What you're looking for:**
```
sk-ant-api03-xxxxxxxxxxxxxxxxxxxxx
```

---

### Step 2: Open App Settings (30 seconds)

In the Kids Learning app:

1. Tap **⚙️ Settings** (top right of home screen)
   - OR tap Settings in bottom navigation
2. Scroll down to find **"Claude AI — Better Conversations"**

---

### Step 3: Paste and Save (30 seconds)

1. **Click** the input field: "API Key (starts with sk-ant-)"
2. **Paste** your API key
3. **Click** "Save Key"
4. See message: ✨ **"Claude AI key saved!"**

---

### Step 4: Test Connection (Optional but recommended)

1. Click **"Test"** button
2. Wait 2-3 seconds
3. Should see: 🎉 **"Claude AI connected!"**

**If test fails:**
- Check you copied the entire key
- Verify key starts with `sk-ant-`
- Check internet connection
- Go to https://console.anthropic.com/account/overview to verify you have API credits

---

### Step 5: Verify It's Active

Go back to home screen:
- Check top-right badge
- Should now show: **✅ Claude AI Active**
- (instead of ⚡ Smart Mode)

## Troubleshooting

### "Invalid key — should start with sk-ant-"
✅ **Solution:**
- Go to console.anthropic.com/account/keys
- Copy key again (completely)
- Paste into settings
- Check for spaces/extra characters

### "Failed: HTTP 401"
✅ **Solution:**
- Key might be invalid/revoked
- Create new key at console.anthropic.com
- Save new key to app

### "Failed: HTTP 429"
✅ **Meaning:** Rate limited or quota exceeded
✅ **Solution:**
- Wait 1 minute
- Check remaining credits
- Try again

### "No response / Timeout"
✅ **Meaning:** API took too long
✅ **Solution:**
- Check internet connection
- Try test connection again
- Local Smart Mode will kick in automatically

### Still showing "⚡ Smart Mode"
✅ **Solution:**
- Refresh browser (F5)
- Clear cache (Ctrl+Shift+Delete)
- Close and reopen app
- Try saving key again

### How to Switch:

**To use Local Smart Mode (disable Claude):**
1. Go to Settings
2. Click "Remove" button (next to API key)
3. Claude key is deleted
4. Badge changes to ⚡ Smart Mode

**To re-enable Claude AI:**
1. Go to Settings
2. Paste API key again
3. Click Save
4. Badge changes back to ✅ Claude AI Active

## FAQ

**Q: Is Claude API safe for kids?**
A: Yes. Claude is designed to be safe, respectful, and educational.

**Q: What if my API key expires?**
A: You'll see an error. Go to console.anthropic.com to create a new key.

**Q: Can I use the same key on multiple devices?**
A: Yes, but all usage counts toward the same quota.

**Q: What if I run out of credits?**
A: Purchase more credits at console.anthropic.com, or switch to local Smart Mode.

**Q: Can I limit spending?**
A: You can monitor usage at console.anthropic.com/account/overview. Set billing limits if needed.

**Q: Does Claude see my child's personal info?**
A: Claude only sees the conversation text. No personal data is sent to Claude.

**Q: What if I'm offline?**
A: The app falls back to local Smart Mode automatically.

**Q: Can I delete all my data?**
A: Yes. Go to Settings → "Clear All Data". This also removes your API key.
