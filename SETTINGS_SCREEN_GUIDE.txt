Error: "Invalid key — should start with sk-ant-"
────────────────────────────────────────────────────
❌ WRONG: "sk-ant-api03-[INCOMPLETE]" (cut off)
❌ WRONG: " sk-ant-..." (space before)
❌ WRONG: "sk-ant-...xyz " (space after)

✅ RIGHT: "sk-ant-api03-xxxxxxxxxxxxxxxxxxxxx" (complete, no spaces)

Action:
  1. Go to https://console.anthropic.com/account/keys
  2. Copy the key COMPLETELY (no extra spaces)
  3. Paste into settings again
  4. Click SAVE KEY


Error: "Failed: HTTP 401" or "Failed to connect"
────────────────────────────────────────────────────
Reasons:
  ❌ API key is invalid/revoked
  ❌ No internet connection
  ❌ API account has no credits

Actions:
  1. Go to https://console.anthropic.com/account/overview
  2. Check if account is active
  3. Verify you have API credits remaining
  4. If no credits, add payment method
  5. Try test connection again


Error: Still shows "⚡ Smart Mode" after saving
────────────────────────────────────────────────────
Actions:
  1. Refresh browser: F5
  2. Clear cache: Ctrl+Shift+Delete
  3. Close and reopen the app
  4. Try saving the key again
  5. Check in Settings again
