❌ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: Blank page / 404 error
→ Solution: Wait 5 minutes, refresh, check that index.html is in root

Problem: Can't see Pages option in Settings
→ Solution: Make sure repo is PUBLIC (not Private)

Problem: App loads but looks broken
→ Solution: Open DevTools (F12), check Console for errors

Problem: Styles/images not loading
→ Solution: GitHub might be case-sensitive (css/ vs CSS/)

Problem: Still not working after 10 minutes
→ Solution: Check GitHub Pages status at: https://www.githubstatus.com
